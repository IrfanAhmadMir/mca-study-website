Java Programming - Unit 2

Object-Oriented Programming in Java

1. Class Fundamentals

What is a Class?

A class is a blueprint or template used to create objects in Java. It defines the data and behavior that objects created from the class can have.

A class generally contains variables and methods. Variables represent the data or state of an object, while methods represent the behavior or actions of an object.

Basic Structure of a Class

The general structure of a Java class is: 


class ClassName {

    // Variables

    // Methods

}

Example: 


class Student {

    String name;
    int age;

    void display() {
        System.out.println(name);
        System.out.println(age);
    }

}

In this example, Student is the class, name and age are variables, and display() is a method.

Components of a Class

A Java class can contain different components such as:

  • Variables
  • Methods
  • Constructors
  • Static and non-static blocks
  • Nested classes and interfaces

Variable Declaration

Variables declared inside a class are used to store data. They can represent the state of an object or information associated with the class. 


class Student {

    String name;
    int age;

}

Here, name and age are variables declared inside the Student class.

Method Declaration

A method is a block of code that performs a particular task. Methods define the behavior of a class or object.

General syntax: 


returnType methodName(parameters) {

    // statements

}

Example: 


class Student {

    void display() {

        System.out.println("Student Details");

    }

}

Modifiers

Modifiers are keywords used to control the accessibility, behavior, or properties of classes, variables and methods.

The syllabus covers two major categories:

  • Access Modifiers
  • Other Modifiers

Access Modifiers

Access modifiers control where a class member can be accessed.

1. private

A private member can be accessed within the class in which it is declared. 


class Student {

    private int age;

}

2. protected

A protected member provides access within the class and also supports access through inheritance. 


class Student {

    protected int age;

}

3. public

A public member can be accessed wherever the class is accessible. 


class Student {

    public String name;

}

4. Default Access

When no access modifier is specified, the member has default access. 


class Student {

    int age;

}

Other Modifiers

Java also provides other modifiers that control the behavior of classes and their members.

Examples include:

  • static
  • final
  • abstract

Constructor

A constructor is a special member of a class that is used when an object is created.

A constructor has the same name as the class and does not have a return type. 


class Student {

    Student() {

        System.out.println("Constructor called");

    }

}

Creating an object: 


Student s = new Student();

When the object is created, the constructor is called.

Constructor with Parameters

A constructor can also receive parameters to initialize object data. 


class Student {

    String name;
    int age;

    Student(String n, int a) {

        name = n;
        age = a;

    }

}

finalize()

The syllabus includes the finalize() method as part of class fundamentals.

It is associated with an object before its memory is reclaimed by garbage collection. 


class Student {

    protected void finalize() {

        System.out.println("Object finalized");

    }

}

Garbage Collection

Garbage collection is the process through which Java automatically manages memory by identifying objects that are no longer needed.

When an object is no longer reachable by the program, it may become eligible for garbage collection. 


Student s = new Student();

s = null;

After s is assigned null, the previously referenced object may become eligible for garbage collection if there are no other references to it.

Passing Parameters to Methods

Parameters allow values to be passed to methods. 


class Calculator {

    int add(int a, int b) {

        return a + b;

    }

}

Calling the method: 


Calculator c = new Calculator();

int result = c.add(10, 20);

System.out.println(result);

Here, 10 and 20 are arguments passed to the method, while a and b are parameters.

Variable Hiding

Variable hiding occurs when a subclass declares a variable with the same name as a variable in its superclass. 


class A {

    int number = 10;

}

class B extends A {

    int number = 20;

}

In this example, the variable declared in class B hides the variable inherited from class A.

Method Overloading

Method overloading occurs when a class contains multiple methods with the same name but different parameter lists.

The parameters can differ in their number or type. 


class Calculator {

    int sum(int a, int b) {

        return a + b;

    }

    double sum(double a, double b) {

        return a + b;

    }

}

Both methods are named sum(), but their parameter types are different.

Constructor Overloading

Constructor overloading means defining multiple constructors in the same class with different parameter lists. 


class Student {

    String name;
    int age;

    Student() {

        name = "Unknown";
        age = 0;

    }

    Student(String n) {

        name = n;

    }

    Student(String n, int a) {

        name = n;
        age = a;

    }

}

Constructor Chaining

Constructor chaining occurs when one constructor calls another constructor.

The this() keyword can be used to call another constructor of the same class. 


class Student {

    String name;
    int age;

    Student() {

        this("Unknown", 0);

    }

    Student(String n, int a) {

        name = n;
        age = a;

    }

}

this Keyword

The this keyword refers to the current object.

It can be used to distinguish instance variables from method or constructor parameters. 


class Student {

    String name;

    Student(String name) {

        this.name = name;

    }

}

Here, this.name refers to the instance variable, while name refers to the constructor parameter.

Static Code Block

A static block is associated with the class rather than with a particular object. It is written using the static keyword. 


class Demo {

    static {

        System.out.println("Static block executed");

    }

}

Non-static Code Block

A non-static block is associated with object initialization and is executed when an object is created. 


class Demo {

    {

        System.out.println("Non-static block executed");

    }

}

2. Inheritance

What is Inheritance?

Inheritance is an object-oriented programming mechanism in which one class acquires properties and methods from another class.

The class whose members are inherited is commonly called the superclass, while the class that inherits them is called the subclass.

Inheritance Mechanism

Java uses the extends keyword to establish inheritance between classes. 


class A {

    int number = 10;

}

class B extends A {

    void display() {

        System.out.println(number);

    }

}

Here, class B inherits from class A.

Role of Access Modifiers in Inheritance

Access modifiers determine which members of a superclass can be accessed by a subclass.

For example, private members are not directly accessible in the subclass, while accessible members can be used according to their access level.

Method Overriding

Method overriding occurs when a subclass provides its own implementation of a method inherited from its superclass. 


class A {

    void display() {

        System.out.println("Class A");

    }

}

class B extends A {

    void display() {

        System.out.println("Class B");

    }

}

The display() method in class B overrides the method inherited from class A.

Variable Shadowing

Variable shadowing occurs when a subclass declares a variable with the same name as a variable inherited from its superclass. 


class A {

    int number = 10;

}

class B extends A {

    int number = 20;

}

The variable declared in class B shadows the variable inherited from class A.

super Keyword

The super keyword is used to refer to members of the superclass.

It can be used to access a superclass variable, superclass method, or superclass constructor.

Accessing Superclass Variable


class A {

    int number = 10;

}

class B extends A {

    int number = 20;

    void display() {

        System.out.println(super.number);

    }

}

Calling Superclass Method


class A {

    void display() {

        System.out.println("Class A");

    }

}

class B extends A {

    void display() {

        super.display();

        System.out.println("Class B");

    }

}

Polymorphism

Polymorphism means the ability of an object or reference to take different forms.

The syllabus covers:

  • Early binding
  • Late binding

Early Binding

Early binding refers to method selection that is determined earlier, such as during compilation.

Method overloading is an example associated with compile-time method selection.

Late Binding

Late binding refers to method selection that is determined at runtime.

Method overriding is associated with runtime polymorphism. 


class A {

    void display() {

        System.out.println("A");

    }

}

class B extends A {

    void display() {

        System.out.println("B");

    }

}

class Main {

    public static void main(String[] args) {

        A obj = new B();

        obj.display();

    }

}

Abstract Class

An abstract class is a class that is declared using the abstract keyword.

It can contain abstract methods as well as other class members. 


abstract class Animal {

    abstract void sound();

}

A subclass can provide the implementation of an abstract method. 


class Dog extends Animal {

    void sound() {

        System.out.println("Dog barks");

    }

}

Interface

An interface provides a way to define a contract that implementing classes follow.

Java classes can implement interfaces using the implements keyword.

Components of Interface Declaration

A basic interface declaration can contain the interface name and its members. 


interface Animal {

    void sound();

}

Implementing an Interface

A class implements an interface using the implements keyword. 


interface Animal {

    void sound();

}

class Dog implements Animal {

    public void sound() {

        System.out.println("Dog barks");

    }

}

3. Exception Handling

What is an Exception?

An exception represents an abnormal condition that occurs during the execution of a program.

Java provides an exception handling mechanism that allows a program to detect and handle such conditions.

Exception Object

In Java, an exception is represented by an object. The object contains information about the exceptional condition.

Throwing an Exception

An exception can be generated during program execution. Java provides mechanisms for throwing and handling exceptions.

Exception Handler

An exception handler is code that handles an exception after it occurs.

Java commonly uses the try, catch and finally statements for exception handling.

Catch or Specify Policy

When a method can produce an exception, the exception must be handled or specified according to Java's exception handling mechanism.

Types of Exceptions

The syllabus classifies exceptions in two ways:

  • Checked and Unchecked Exceptions
  • Built-in and User-defined Exceptions

Checked Exceptions

Checked exceptions are exceptions that are checked by the compiler and generally need to be handled or specified.

Unchecked Exceptions

Unchecked exceptions are associated with runtime conditions and are not required to be handled in the same way as checked exceptions.

Built-in Exceptions

Java provides predefined exception classes for different exceptional situations.

Examples include:

  • ArithmeticException
  • NullPointerException
  • ArrayIndexOutOfBoundsException

User-defined Exceptions

Java allows programmers to create custom exception classes for application-specific situations.

try-catch

The try block contains code that may produce an exception, while the catch block handles the exception. 


try {

    int result = 10 / 0;

}
catch (ArithmeticException e) {

    System.out.println("Cannot divide by zero");

}

finally

The finally block is used with exception handling and is used for code that should execute after the try/catch processing. 


try {

    int result = 10 / 2;

}
catch (ArithmeticException e) {

    System.out.println("Exception occurred");

}
finally {

    System.out.println("Finally block");

}

throws Keyword

The throws keyword is used in a method declaration to specify exceptions that the method may throw. 


void readFile() throws Exception {

    // code

}

The method does not necessarily handle the exception itself. It specifies the exception so that the caller can handle it.

throw Keyword

The throw keyword is used to manually throw an exception. 


class Test {

    static void check(int age) {

        if (age < 18) {

            throw new ArithmeticException("Age is less than 18");

        }

    }

}

Custom Exception

A custom exception is an exception created by the programmer for a particular application requirement. 


class AgeException extends Exception {

    AgeException(String message) {

        super(message);

    }

}

The custom exception can then be used in a program. 


class Test {

    static void checkAge(int age) throws AgeException {

        if (age < 18) {

            throw new AgeException("Age must be 18 or above");

        }

    }

}

Chained Exceptions

Chained exceptions allow one exception to be associated with another exception.

This can be useful when one exception occurs because of another underlying exception. 


try {

    try {

        int x = 10 / 0;

    }
    catch (ArithmeticException e) {

        throw new Exception("Another exception", e);

    }

}
catch (Exception e) {

    System.out.println(e);

}

Complete Exception Handling Example


class Division {

    static int divide(int a, int b) {

        return a / b;

    }

    public static void main(String[] args) {

        try {

            int result = divide(10, 0);

            System.out.println(result);

        }
        catch (ArithmeticException e) {

            System.out.println("Cannot divide by zero");

        }
        finally {

            System.out.println("Program completed");

        }

    }

}
