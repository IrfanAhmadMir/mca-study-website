Java Programming - Unit 1

Introduction to Java and Programming Fundamentals

1. Introduction to Java

Java is a high-level, object-oriented programming language. It is designed to be portable across different platforms.

Features of Java

  • Object-oriented
  • Platform independent
  • Simple
  • Secure
  • Robust
  • Portable
  • Multithreaded

2. JVM and Bytecode

What is JVM?

JVM stands for Java Virtual Machine. It is the part of the Java platform that executes Java bytecode.

The JVM provides the environment in which Java bytecode can run. This is one of the important reasons Java programs can be used across different platforms.

What is Bytecode?

When a Java program is written, the source code is compiled by the Java compiler. The compiler converts the Java source code into an intermediate form called bytecode.

Java bytecode is stored in a .class file and is executed by the JVM.

How Java Code Executes

The basic execution process can be represented as:

Java Source Code → Compiler → Bytecode → JVM → Program Execution

Example

Suppose we create a Java file called Hello.java. The Java compiler converts it into bytecode, producing Hello.class. The JVM then executes this bytecode.

Important Exam Point

Remember the difference:

  • Source code: Java program written by the programmer.
  • Bytecode: Intermediate code generated by the Java compiler.
  • JVM: Executes the bytecode.

3. Lexical Issues

Lexical issues deal with the basic elements and rules used to write a Java program. These elements form the building blocks of Java source code.

1. Identifiers

Identifiers are names given to programming elements such as variables, methods, classes and objects.

Example: studentName, calculateMarks, Student

2. Keywords

Keywords are reserved words in Java that have a predefined meaning. They cannot normally be used as identifiers.

Examples: class, public, static, int, if

3. Literals

Literals are fixed values written directly in a Java program.

Examples: 10, 3.14, 'A', "Hello", true

4. Operators

Operators are symbols used to perform operations on values and variables.

Examples: +, -, *, /, ==

5. Separators

Separators are symbols used to separate different parts of Java source code.

Examples include: ;, ,, { }, ( ), [ ]

6. Comments

Comments are used to explain code and are ignored during program execution.

Single-line comment: // This is a comment

Multi-line comment: /* This is a comment */

Quick Revision

  • Identifier: Name given to a program element.
  • Keyword: Reserved word with a predefined meaning.
  • Literal: Fixed value written in the program.
  • Operator: Performs an operation.
  • Separator: Separates parts of source code.
  • Comment: Used to explain code.

4. JDK and PATH

What is JDK?

JDK stands for Java Development Kit. It provides the tools required to develop, compile and run Java programs.

JDK, JRE and JVM

  • JDK: Used for Java development and contains development tools.
  • JRE: Provides the environment required to run Java applications.
  • JVM: Executes Java bytecode.

What is PATH?

PATH is an environment variable used by the operating system to locate executable programs and commands.

When Java's executable directory is included in PATH, commands such as java and javac can be executed from the command line.

Important Java Commands

  • java -version — checks the installed Java version.
  • javac — Java compiler command.
  • java — command used to run a Java program.

Example

If the file is named Hello.java, it can be compiled using:

javac Hello.java

This produces a class file containing Java bytecode. The program can then be executed using the Java command.

Quick Revision

  • JDK: Development kit.
  • JRE: Runtime environment.
  • JVM: Executes bytecode.
  • PATH: Helps the operating system locate Java commands.
  • javac: Java compiler.
  • java: Runs a Java program.

5. Java Program Structure

Basic Structure of a Java Program

A Java program is generally organized using classes and methods. The statements inside these methods define what the program does.

Example

public class HelloWorld {

public static void main(String[] args) {

System.out.println("Hello World");

}

}

Understanding the Program

  • class: Defines a class in Java.
  • public: An access modifier.
  • static: Allows the main method to be associated with the class without creating an object first.
  • void: Indicates that the method does not return a value.
  • main(): The standard entry point used to start a Java application.
  • String[] args: Receives command-line arguments.
  • System.out.println(): Displays output on the console.

Important Point

The Java source file is normally saved with the .java extension. After compilation, bytecode is generated in a .class file.

Compilation and Execution

If the source file is named HelloWorld.java, it can be compiled using:

javac HelloWorld.java

The resulting class can then be executed using:

java HelloWorld

Quick Revision

  • Java programs are organized using classes and methods.
  • The main() method is the standard starting point of a Java application.
  • javac compiles Java source code.
  • java runs the compiled program.
  • Source file extension: .java
  • Compiled bytecode file extension: .class

6. Data Types

What is a Data Type?

A data type specifies what kind of value a variable can store. Java provides different data types for storing different kinds of information.

Primitive Data Types

Java has eight primitive data types:

  • byte — stores small integer values.
  • short — stores integer values larger than byte.
  • int — commonly used for integer values.
  • long — used for larger integer values.
  • float — used for decimal values.
  • double — used for decimal values with greater precision.
  • char — stores a single character.
  • boolean — stores either true or false.

Examples

int age = 20;

double price = 99.50;

char grade = 'A';

boolean passed = true;

Important Point

Primitive data types are the basic built-in data types provided by Java. They are used directly to store values.

Quick Revision

  • Java provides eight primitive data types.
  • Integer types include byte, short, int and long.
  • Floating-point types include float and double.
  • char stores a character.
  • boolean stores true or false.

7. Variables

What is a Variable?

A variable is a named memory location used to store a value. The value stored in a variable can be used and, depending on how the variable is declared, changed during program execution.

Variable Declaration

A variable is declared by specifying its data type followed by the variable name.

int age;

Here, int is the data type and age is the variable name.

Variable Initialization

Initialization means assigning an initial value to a variable.

int age = 20;

Declaration and Initialization Together

A variable can be declared and initialized in the same statement.

double marks = 85.5;

Examples

int number = 10;

char grade = 'A';

boolean result = true;

String name = "Irfan";

Changing a Variable's Value

The value of a variable can be changed by assigning a new value to it, provided the new value is compatible with its data type.

int age = 20;

age = 21;

Quick Revision

  • Declaration: Creating a variable by specifying its type and name.
  • Initialization: Giving a variable its initial value.
  • Assignment: Giving or changing the value of a variable.
  • A variable has a name and a data type.

8. Arrays

What is an Array?

An array is a collection of elements of the same data type. It allows multiple values to be stored under a single variable name.

Why Use Arrays?

Suppose we want to store the marks of five students. Instead of creating five separate variables, we can store all the marks in one array.

Declaring an Array

An array can be declared by specifying the data type followed by square brackets and the array name.

int marks[];

Creating an Array

Memory for the array can be allocated using the new keyword.

marks = new int[5];

This creates an integer array capable of storing five values.

Declaration and Initialization

An array can also be declared and initialized in a single statement.

int marks[] = {80, 75, 90, 85, 88};

Array Index

Array indexing starts from 0 in Java.

For example:

int marks[] = {80, 75, 90};

  • marks[0] → 80
  • marks[1] → 75
  • marks[2] → 90

Accessing an Array Element

Individual elements can be accessed using their index.

System.out.println(marks[0]);

Changing an Array Element

An element can be changed by assigning a new value to its index.

marks[1] = 95;

Example Program

int marks[] = {80, 75, 90};

System.out.println(marks[0]);
System.out.println(marks[1]);
System.out.println(marks[2]);

Important Points

  • An array stores multiple values of the same data type.
  • Array indexing starts from 0.
  • The size of an array is fixed after it is created.
  • Elements are accessed using their index.
  • Arrays can store primitive values as well as references to objects.

Quick Revision

  • Array: Collection of elements of the same type.
  • Index: Position used to access an array element.
  • First index: 0
  • Creation: Can use the new keyword.

9. Operators

What is an Operator?

An operator is a symbol that tells Java to perform a particular operation on one or more values or variables.

1. Arithmetic Operators

Arithmetic operators are used to perform mathematical operations.

  • + — Addition
  • - — Subtraction
  • * — Multiplication
  • / — Division
  • % — Modulus

Example: int result = 10 + 5;

2. Relational Operators

Relational operators compare two values and produce a boolean result.

  • == — Equal to
  • != — Not equal to
  • > — Greater than
  • < — Less than
  • >= — Greater than or equal to
  • <= — Less than or equal to

Example: age >= 18

3. Logical Operators

Logical operators are used to combine or modify boolean conditions.

  • && — Logical AND
  • || — Logical OR
  • ! — Logical NOT

Example: age >= 18 && citizen == true

4. Assignment Operators

Assignment operators are used to assign values to variables.

  • =
  • +=
  • -=
  • *=
  • /=
  • %=

Example: marks += 5;

5. Unary Operators

Unary operators operate on a single operand.

  • ++ — Increment
  • -- — Decrement
  • + — Unary plus
  • - — Unary minus
  • ! — Logical NOT

Example: count++;

6. Conditional Operator

The conditional operator is also called the ternary operator. It provides a short way to express a simple conditional expression.

Syntax:

condition ? value1 : value2

Example: int max = (a > b) ? a : b;

Example

int a = 10;
int b = 5;
int sum = a + b;

System.out.println(sum);

Quick Revision

  • Arithmetic: Mathematical calculations.
  • Relational: Compares values.
  • Logical: Combines boolean conditions.
  • Assignment: Assigns values to variables.
  • Unary: Works with one operand.
  • Conditional: Short form of a simple conditional expression.

10. Control Statements

What are Control Statements?

Control statements are used to control the order in which statements are executed in a Java program.

1. if Statement

The if statement executes a block of code when a specified condition is true.

Example: if (age >= 18) { ... }

2. if-else Statement

The if-else statement provides two possible paths. One block executes when the condition is true and another executes when it is false.

Example: if (marks >= 40) { ... } else { ... }

3. switch Statement

The switch statement is used when different actions need to be performed based on the value of an expression.

Example: switch (day) { ... }

4. for Loop

The for loop is commonly used when a block of code needs to be repeated a specific number of times.

Example: for (int i = 0; i < 5; i++) { ... }

5. while Loop

The while loop repeatedly executes a block of code as long as its condition remains true.

Example: while (count < 5) { ... }

6. do-while Loop

The do-while loop executes its body first and checks the condition afterwards.

Example: do { ... } while (count < 5);

7. break Statement

The break statement is used to terminate a loop or switch statement.

Example: break;

8. continue Statement

The continue statement skips the remaining part of the current loop iteration and proceeds with the next iteration.

Example: continue;

Quick Revision

  • if: Executes code when a condition is true.
  • if-else: Provides two possible execution paths.
  • switch: Selects an action based on a value.
  • for: Repeats code using a loop structure.
  • while: Repeats while a condition is true.
  • do-while: Executes once before checking the condition.
  • break: Terminates the loop or switch.
  • continue: Skips the current iteration.
