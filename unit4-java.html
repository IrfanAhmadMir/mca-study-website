Java GUI Programming and Networking

1. Event-Driven Programming

Event-driven programming is a programming approach in which the flow of a program is determined by events generated by the user or the system.

Examples of events include clicking a button, pressing a keyboard key, moving the mouse, or closing a window.

Examples of Events

  • Mouse click
  • Mouse movement
  • Keyboard input
  • Button click
  • Window actions

Basic Event Flow


User Action
     ↓
Event Generated
     ↓
Event Object
     ↓
Listener Receives Event
     ↓
Event Handler Executes
     ↓
Program Responds

2. Java 1.1 Event Delegation Model

The event delegation model is a mechanism in Java where an event source generates an event and delegates the handling of that event to a listener object.

Main Components

The event delegation model consists mainly of three important components:

  • Source Object
  • Event Object
  • Listener Object

Event Delegation Model


       SOURCE OBJECT
       (Button)
           |
           | generates
           ↓
       EVENT OBJECT
       (ActionEvent)
           |
           | delivered to
           ↓
      LISTENER OBJECT
      (ActionListener)
           |
           ↓
      EVENT HANDLER
           |
           ↓
       Response

Source Object

The source object is the component that generates an event.

For example, a button can generate an action event when the user clicks it. 


Button button = new Button("Click");

Event Object

An event object contains information about an event that has occurred.

For example, ActionEvent represents an action event.

Listener Object

A listener object receives an event and performs the required action. 


class MyListener implements ActionListener {

    public void actionPerformed(ActionEvent e) {

        System.out.println("Button clicked");

    }
}

3. Methods Associated with Source, Event and Listener Objects

Source Object Methods

A source object provides methods to register listeners that should receive events. 


button.addActionListener(listener);

Event Object

Event objects provide information about the event that occurred. 


public void actionPerformed(ActionEvent e) {

    System.out.println("Event received");

}

Listener Object

Listener interfaces define methods that are called when particular events occur. 


class MyListener implements ActionListener {

    public void actionPerformed(ActionEvent e) {

        System.out.println("Button clicked");

    }

}

4. Low-Level vs Semantic Events

Low-Level Events

Low-level events represent basic interactions with components or the input system.

Examples include mouse and keyboard events.

  • Mouse events
  • Keyboard events
  • Focus events
  • Component events

Semantic Events

Semantic events represent meaningful actions performed by the user.

For example, clicking a button can generate an ActionEvent. 


button.addActionListener(e -> {

    System.out.println("Button action performed");

});

5. Adapter Classes

Adapter classes provide default implementations of listener interfaces that contain multiple methods.

They allow a programmer to override only the methods that are required.

Example


import java.awt.event.*;

class MyWindow extends WindowAdapter {

    public void windowClosing(WindowEvent e) {

        System.out.println("Window closing");

    }

}

Here, WindowAdapter is used instead of implementing all methods of the WindowListener interface.

6. Inner Classes

An inner class is a class declared inside another class.

Inner classes are useful when a class is closely related to another class. 


class Outer {

    class Inner {

        void display() {

            System.out.println("Inner class");

        }

    }

}

Inner Class for Event Handling


class MyGUI {

    class ButtonHandler implements ActionListener {

        public void actionPerformed(ActionEvent e) {

            System.out.println("Button clicked");

        }

    }

}

7. Anonymous Inner Classes

An anonymous inner class is a class without a name. It is commonly used when an object is needed only once. 


button.addActionListener(new ActionListener() {

    public void actionPerformed(ActionEvent e) {

        System.out.println("Button clicked");

    }

});

This allows the event handler to be written directly when the listener is registered.

8. Adding GUI Elements to Applet

Java applets historically allowed GUI components to be added to an applet using Java's GUI classes.

GUI elements can include components such as buttons, labels and text fields. 


import java.applet.Applet;
import java.awt.*;

public class MyApplet extends Applet {

    public void init() {

        Button button = new Button("Click");

        add(button);

    }

}

9. Networking in Java

Java provides networking classes and interfaces for communication between computers over a network.

Java networking APIs can be used to develop applications that communicate with other systems.

TCP/IP

TCP/IP is a collection of communication protocols used for communication over computer networks.

Socket

A socket provides an endpoint for communication between two applications over a network.

        CLIENT

           ↓
      NETWORK

        SERVER

10. TCP/IP Server Sockets in Java

Java provides the ServerSocket class for creating a server that listens for incoming client connections.

Basic Server Program


import java.net.*;

class Server {

    public static void main(String[] args)
            throws Exception {

        ServerSocket server =
            new ServerSocket(5000);

        System.out.println("Server started");

        Socket socket =
            server.accept();

        System.out.println("Client connected");

        socket.close();

        server.close();

    }

}

Important Steps

  1. Create a ServerSocket.
  2. Specify a port number.
  3. Wait for a client using accept().
  4. Communicate with the client.
  5. Close the socket.

11. Client Socket

A client can connect to a server using the Socket class. 


import java.net.*;

class Client {

    public static void main(String[] args)
            throws Exception {

        Socket socket =
            new Socket("localhost", 5000);

        System.out.println("Connected to server");

        socket.close();

    }

}

Client-Server Communication


        SERVER
   ServerSocket
        |
        | accept()
        |
        ↓
      Socket
        ↑
        |
        | connect()
        |
      Socket
        |
       CLIENT

12. File Transfer Using Java Networking

Java networking can be used to transfer files between a client and a server.

A simplified file-transfer process is: 


Client selects file
        ↓
Client opens connection
        ↓
File converted to bytes
        ↓
Bytes sent through socket
        ↓
Server receives bytes
        ↓
Server writes bytes to file

Conceptual Example


FileInputStream input =
    new FileInputStream("file.txt");

OutputStream output =
    socket.getOutputStream();

byte[] buffer = new byte[1024];

int bytesRead;

while ((bytesRead = input.read(buffer)) != -1) {

    output.write(buffer, 0, bytesRead);

}

input.close();
output.close();

13. Chatting Application Using Java

Java sockets can also be used to create basic client-server chatting applications.

The client and server establish a socket connection and exchange messages through input and output streams. 


             SERVER
                |
                |
          ServerSocket
                |
                ↓
             Socket
             ↕     ↕
       Input     Output
             ↕     ↕
             Socket
                |
                |
             CLIENT

Basic Chat Flow

  1. Server starts and listens on a port.
  2. Client connects to the server.
  3. A socket connection is established.
  4. Client sends a message.
  5. Server receives the message.
  6. Server sends a response.
  7. The process continues for further messages.
