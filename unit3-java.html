Java Programming - Unit 3

Advanced Java Concepts

1. Packages

A package in Java is a collection of related classes, interfaces and other components. Packages help organize Java programs and provide a way to manage classes.

Creating a Package

A package can be created using the package keyword. 

package mypackage;

public class Student {

    public void display() {
        System.out.println("Student class");
    }

}

Here, mypackage is the package name and Student belongs to that package.

Importing a Package

The import keyword is used to access classes from another package. 

import mypackage.Student;

class Test {

    public static void main(String[] args) {

        Student s = new Student();

        s.display();
    }
}

Importing Multiple Classes

Individual classes can be imported from a package. 

import java.util.Scanner;
import java.util.ArrayList;

Importing All Classes from a Package

The * symbol can be used to import all accessible classes from a package. 

import java.util.*;

CLASSPATH Variable

The CLASSPATH variable tells Java where to search for classes and packages when compiling or executing a Java program.

It can contain directories and JAR files where Java classes are located.

static Import

Static import allows static members of a class to be used without writing the class name every time. 

import static java.lang.Math.*;

class Demo {

    public static void main(String[] args) {

        System.out.println(sqrt(25));
        System.out.println(pow(2, 3));

    }
}

Without static import, we normally write: 

System.out.println(Math.sqrt(25));
System.out.println(Math.pow(2, 3));

2. Strings

A String represents a sequence of characters. Java provides the String class for working with text.

Creating Strings

Strings can be created using a string literal. 

String name = "Irfan";

A String object can also be created using the new keyword. 

String name = new String("Irfan");

Mutable and Immutable Strings

A String object in Java is immutable. This means that once a String object is created, its content cannot be changed. 

String name = "Java";

name = name + " Programming";

In this example, the original String object is not modified. A new String is created.

String Operations

Java provides several methods for performing operations on strings.

length()

String text = "Java";

System.out.println(text.length());

Output: 

4

charAt()

String text = "Java";

System.out.println(text.charAt(0));

Output: 

J

concat()

String first = "Java";
String second = "Programming";

String result = first.concat(" " + second);

System.out.println(result);

Output: 

Java Programming

toUpperCase() and toLowerCase()

String text = "Java Programming";

System.out.println(text.toUpperCase());

System.out.println(text.toLowerCase());

equals()

The equals() method compares the contents of two strings. 

String a = "Java";
String b = "Java";

System.out.println(a.equals(b));

Output: 

true

StringBuilder

StringBuilder is used when we need to modify strings frequently. Unlike String, it is mutable. 

StringBuilder text = new StringBuilder("Java");

text.append(" Programming");

System.out.println(text);

Output: 

Java Programming

StringBuffer

StringBuffer is another mutable character sequence. It provides methods for modifying text. 

StringBuffer text = new StringBuffer("Java");

text.append(" Programming");

System.out.println(text);

3. Threads

A thread is a lightweight unit of execution inside a program. Threads allow different tasks to execute concurrently.

Creating Threads in Java

One common way to create a thread is by extending the Thread class. 

class MyThread extends Thread {

    public void run() {

        System.out.println("Thread is running");

    }
}

class Demo {

    public static void main(String[] args) {

        MyThread t = new MyThread();

        t.start();

    }
}

Using Runnable

Another way of creating a thread is by implementing the Runnable interface. 

class MyTask implements Runnable {

    public void run() {

        System.out.println("Thread is running");

    }
}

class Demo {

    public static void main(String[] args) {

        MyTask task = new MyTask();

        Thread t = new Thread(task);

        t.start();

    }
}

Thread Lifecycle

A thread passes through different states during its lifetime. 


        NEW
         |
         ↓
      RUNNABLE
         |
         ↓
       RUNNING
       /     \
      ↓       ↓
  WAITING   BLOCKED
      \       /
       \     /
        ↓   ↓
      RUNNABLE
         |
         ↓
    TERMINATED

Important thread states include:

  • New - Thread object has been created but has not started.
  • Runnable - Thread is ready to run.
  • Running - Thread is executing.
  • Blocked - Thread is waiting to acquire a lock.
  • Waiting - Thread is waiting for another thread.
  • Terminated - Thread has completed execution.

Multithreading in Java

Multithreading means executing multiple threads within the same program. 

class Task extends Thread {

    public void run() {

        for(int i = 1; i <= 5; i++) {

            System.out.println(i);

        }

    }
}

class Demo {

    public static void main(String[] args) {

        Task t1 = new Task();
        Task t2 = new Task();

        t1.start();
        t2.start();

    }
}

Synchronization

Synchronization is used when multiple threads access shared data. It helps prevent multiple threads from modifying the same critical section at the same time. 

class Counter {

    int count = 0;

    synchronized void increment() {

        count++;

    }
}

Inter-Process Communication (IPC) in Threads

Threads can communicate with each other when working with shared resources. Java provides mechanisms such as wait(), notify() and notifyAll() for thread communication. 

class Shared {

    synchronized void waitForTask() {

        try {

            wait();

        } catch (InterruptedException e) {

            System.out.println(e);

        }

    }

    synchronized void completeTask() {

        notify();

    }
}

4. I/O Streams

Java I/O (Input/Output) provides classes and interfaces for reading data from sources and writing data to destinations.

Types of I/O Streams

The syllabus covers the following streams:

  • Byte Streams
  • Character Streams
  • Buffered Streams
  • Data Streams
  • Object Streams
  • Standard Streams

Byte Streams

Byte streams are used for handling data in the form of bytes. Important classes include InputStream and OutputStream. 

FileInputStream input =
    new FileInputStream("input.txt");

int data;

while((data = input.read()) != -1) {

    System.out.print((char)data);

}

input.close();

Character Streams

Character streams are designed for handling character data. Important classes include Reader and Writer. 

FileReader reader =
    new FileReader("input.txt");

int data;

while((data = reader.read()) != -1) {

    System.out.print((char)data);

}

reader.close();

Buffered Streams

Buffered streams use a buffer to improve input and output performance. 

BufferedReader reader =
    new BufferedReader(
        new FileReader("input.txt")
    );

String line;

while((line = reader.readLine()) != null) {

    System.out.println(line);

}

reader.close();

Data Streams

Data streams allow Java primitive data types to be read and written in a machine-independent manner. 

DataOutputStream output =
    new DataOutputStream(
        new FileOutputStream("data.dat")
    );

output.writeInt(100);
output.writeDouble(25.5);

output.close();

Object Streams

Object streams are used to read and write objects. They are commonly used with object serialization. 

ObjectOutputStream output =
    new ObjectOutputStream(
        new FileOutputStream("student.dat")
    );

output.writeObject(student);

output.close();

Standard Streams

Java provides three standard streams:

  • System.in - Standard input
  • System.out - Standard output
  • System.err - Standard error
System.out.println("Hello Java");

System.err.println("Error message");

File I/O Basics

File I/O allows Java programs to read data from files and write data to files.

Writing to a File

FileWriter writer =
    new FileWriter("output.txt");

writer.write("Hello Java");

writer.close();

Reading from a File

FileReader reader =
    new FileReader("output.txt");

int data;

while((data = reader.read()) != -1) {

    System.out.print((char)data);

}

reader.close();

Serializing Objects

Serialization is the process of converting an object into a byte stream so that it can be stored or transmitted.

A class whose objects need to be serialized generally implements the Serializable interface. 

import java.io.Serializable;

class Student implements Serializable {

    String name;
    int age;

}

The object can then be written using ObjectOutputStream. 

ObjectOutputStream output =
    new ObjectOutputStream(
        new FileOutputStream("student.dat")
    );

output.writeObject(student);

output.close();

Deserializing an Object

Deserialization is the process of reconstructing an object from a byte stream. 

ObjectInputStream input =
    new ObjectInputStream(
        new FileInputStream("student.dat")
    );

Student s =
    (Student) input.readObject();

input.close();
